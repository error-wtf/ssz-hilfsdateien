## 2. The Observable Is a Curve Integral

LIGO measures:

```
ΔΦ(t) = Φ_x(t) - Φ_y(t)
```

where each arm phase is a line integral of the photon wavevector:

```
Φ_i(t) = ∫_{γ_i} k_μ(x, t) dx^μ
```

This is a **line integral of the second kind** — integrating a vector
field along a path. It is not a scalar measurement at a point.

### 2.1 Standard GR Response

For a + polarised GW: h_xx = +h(t), h_yy = -h(t), the metric is:

```
g_ij = diag(1 + h(t), 1 - h(t), 1)
```

Null geodesic along arm x (length L):

```
Φ_x(t) = (ω_L / c) ∫_0^L √(1 + h(t - ℓ/c)) dℓ
        ≈ (ω_L L / c) (1 + ½ <h>_x)
```

where <h>_x is the light-travel-time average of h(t - ℓ/c):

```
<h>_x = (1/L) ∫_0^L h(t - ℓ/c) dℓ
```

Similarly Φ_y with -h_yy:

```
ΔΦ(t) = (ω_L L / c) [<h>_x - <h>_y]
       = (ω_L L / c) · 2 <h(t)>
```

This gives:

```
h_eff(t) = ΔΦ · λ/(4π L) = <h(t)>_ret   ✓
```

**This is the correct retarded integral: light collects the GW
along the arm during transit, not instantaneously.**

## 3. Geometric Algebra Formulation

### 3.1 Local Arm Basis

Each arm defines a unit basis vector in the arm plane:

```
e_x = (1, 0)   (arm x direction)
e_y = (0, 1)   (arm y direction)
```

In GA, these are grade-1 elements (vectors).

### 3.2 Rotor

A rotation in the (e_x, e_y) plane by angle θ is generated by
the bivector B = e_x ∧ e_y = e_x e_y (in GA notation):

```
R(θ) = exp(-θ/2 · B) = cos(θ/2) - sin(θ/2) · e_x e_y
```

The rotor acts on vectors by the double-sided product:

```
e_x → R e_x R†  =  e_x cos θ - e_y sin θ
e_y → R e_y R†  =  e_x sin θ + e_y cos θ
```

This is exactly the SO(2) rotation matrix acting on the arm directions.

### 3.3 SSZ Scale + Twist

SSZ modifies the local frame as:

```
e_i → s(r,t) · R(θ(r,t)) e_i R(θ(r,t))†
```

where:
- `s(r,t) = 1 + Ξ(r,t)` is the RSG scale factor (already in corpus)
- `R(θ)` is the SSZ-induced twist rotor (not yet derived from spin connection)

For a GW + SSZ background:

```
e_x^SSZ(t) = s(t) · [e_x cos θ(t) - e_y sin θ(t)]
e_y^SSZ(t) = s(t) · [e_x sin θ(t) + e_y cos θ(t)]
```

### 3.4 Projected Phase Along Each Arm

The photon wavevector k is projected onto the (twisted) arm direction:

```
Φ_x^SSZ(t) = ∫_0^L < k(ℓ, t-ℓ/c), e_x^SSZ(ℓ, t-ℓ/c) > dℓ
```

where < · , · > is the inner product. For a GW + SSZ:

```
< k, e_x^SSZ > = (ω_L/c) · s · [cos θ · (1 + h_+/2) - sin θ · h_×/2]
```

(for small GW amplitude, mixing + and × via the twist angle θ).

## 4. Retarded Integration vs Instantaneous

The retarded integral is essential. It captures the fact that light
at position ℓ at time t was emitted at time t - ℓ/c:

```
Φ_x^ret(t) = ∫_0^L F_x(ℓ, t - ℓ/c) dℓ
```

Compared to the instantaneous approximation:

```
Φ_x^inst(t) ≈ L · F_x(0, t)
```

The difference is the **transit time correction**. For LIGO (L = 4 km,
GW frequency f ~ 100 Hz):

```
2πfL/c = 2π × 100 × 4000 / 3e8 ≈ 8.4 × 10^{-3} rad
```

This is small for LIGO (arm is much shorter than GW wavelength),
so the retarded and instantaneous results agree well in the 20–200 Hz band.
For LISA (L ~ 2.5 Gm), the retarded correction is essential.
