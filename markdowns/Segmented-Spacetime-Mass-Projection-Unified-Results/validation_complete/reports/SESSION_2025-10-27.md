## 🎓 Lessons Learned

1. **Git LFS is essential for media-heavy projects**
   - Without it, repo becomes bloated
   - Push/pull becomes slow
   - Collaborators struggle

2. **Audience-specific documentation works**
   - Scientists → Papers & Results
   - Developers → Code & Tests
   - Students → Tutorials & Videos

3. **Incremental updates can become messy**
   - Sometimes complete restructure is better
   - Backup before major changes
   - Keep old version for reference

4. **Session summaries are valuable**
   - Helps future contributors
   - Tracks decision rationale
   - Documents context

5. **TODO lists beat scattered notes**
   - Centralized checklist
   - Prioritization clear
   - Progress trackable
