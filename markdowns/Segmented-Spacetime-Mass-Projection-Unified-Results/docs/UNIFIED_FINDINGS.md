**Answer:** Geometric necessity.

For bound orbit:
```

E_pot ~ GMm/r          (potential)

Therefore: E_pot/E_kin ~ 2

This factor-of-2 is UNIVERSAL for gravitationally bound systems.
```

**Answer:** Measure of spacetime discretization.

```
Xi = 0:     Perfectly continuous (standard GR)

Xi → 1:     Maximally discrete (quantum gravity regime)

```

Far (r > r*):          Weak curvature → Both agree
At r = r*:             Perfect balance → D_SSZ = D_GR

The ratio r*/r_s ≈ 1.387 arises from balance equation
that depends only on (Xi_max, φ), not on M!
