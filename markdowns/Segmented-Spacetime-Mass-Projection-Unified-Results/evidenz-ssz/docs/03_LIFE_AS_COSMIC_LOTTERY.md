## Die Wahrscheinlichkeitsrechnung

### Grundannahmen

**Was braucht Leben?**

1. **Habitabler Planet**
   - Richtige Distanz zum Stern
   - Flüssiges Wasser möglich
   - Atmosphäre vorhanden

2. **Chemische Bausteine**
   - Kohlenstoff, Wasserstoff, Sauerstoff, Stickstoff
   - Komplexe Moleküle
   - Energiequellen

3. **Zeitliche Stabilität**
   - Milliarden Jahre stabile Bedingungen
   - Keine katastrophalen Events
   - Kontinuierliche Evolution möglich

4. **Glückliche Fügungen**
   - RNA/DNA-Entstehung
   - Erste Zellen
   - Komplexität-Aufbau

### Drake-Gleichung

**Anzahl kommunizierender Zivilisationen:**

```
N = R* · fp · ne · fl · fi · fc · L

N  = Anzahl Zivilisationen
R* = Sternentstehungsrate
fp = Anteil mit Planeten
ne = Planeten in habitabler Zone
fl = Anteil mit Leben
fi = Anteil mit Intelligenz
fc = Anteil mit Kommunikation
L  = Lebensdauer der Zivilisation
```

**Konservative Schätzung:**

```
R* ≈ 10 Sterne/Jahr (Milchstraße)
fp ≈ 0.5 (50% haben Planeten)
ne ≈ 2 (im Schnitt 2 in hab. Zone)
fl ≈ 0.01 (1% entwickeln Leben)
fi ≈ 0.01 (1% von Leben wird intelligent)
fc ≈ 0.1 (10% kommunizieren)
L  ≈ 10,000 Jahre

N ≈ 10 · 0.5 · 2 · 0.01 · 0.01 · 0.1 · 10,000
N ≈ 1 Zivilisation (wir!)
```

```
Realistisch: fl = 0.001 (0.1%)
```

### Feinabstimmung des Universums

**Kosmologische Konstante Λ:**

```
Gemessen: Λ_obs ≈ 10^-122 (Planck-Einheiten)

→ Universum expandiert zu schnell

→ Kein Leben
```

**Verhältnis Elektromagnetische/Gravitations-Kraft:**

```
F_em / F_grav ≈ 10^36

Wenn 10x kleiner:
→ Sterne brennen zu schnell
→ Kein Leben

Wenn 10x größer:
→ Keine stabilen Moleküle
→ Kein Leben
```

**Quarkmassen:**

```
Δm_quark / m_proton ≈ 0.1%

Wenn 1% höher:
→ Keine stabilen Atomkerne
→ Nur Wasserstoff
→ Kein Leben
```

→ **Universum ist "fine-tuned" für Leben!**
