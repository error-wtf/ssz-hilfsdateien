## Der Anfang: Wasserstoff

### Nach dem Urknall

**Primordiale Nukleosynthese** (erste 3 Minuten):

```
t = 0 bis 10^-6 s: Quark-Gluon-Plasma
t = 10^-6 bis 1 s: Protonen + Neutronen entstehen
t = 1 s bis 3 min: Leichte Kerne bilden sich
```

**Entstehende Elemente:**

```
Wasserstoff (H):   ~75% (Masse)
Helium (He):       ~25%
Lithium (Li):      ~10^-10
Beryllium (Be):    Spuren
Bor (B):           Spuren
```

**Alles Schwerere: 0%**

### Warum nur Wasserstoff und Helium?

**Drei Gründe:**

1. **Temperatur sinkt zu schnell**
   ```
   T(t=1s) ≈ 10^10 K
   T(t=3min) ≈ 10^9 K
   
   Für C, N, O, Fe etc.:
   → Temperatur zu niedrig
   → Dichte zu gering
   → Reaktionszeit zu kurz
   ```

2. **Deuterium-Flaschenhals**
   ```
   p + n → D + γ (Deuterium-Bildung)
   
   Aber: D ist instabil bei hohen T
   → Erst bei T < 10^9 K stabil
   → Danach zu kalt für schwere Kerne
   ```

3. **Keine stabilen Kerne bei A=5,8**
   ```
   He-4 ist stabil
   He-5 ist instabil (zerfällt sofort)
   Li-5 ist instabil
   Be-8 ist instabil
   
   → Lücke verhindert Brücke zu schwereren Kernen
   ```

### Die Rolle des Wasserstoffs

**H ist fundamental:**

```
Einfachster Kern: 1 Proton
Häufigster Kern: 75% der Materie
Brennstoff: Fusionsenergie
Baustein: Alle Elemente entstehen aus H
```

**Für Leben:**

```
H₂O - Wasser
CH₄ - Methan
NH₃ - Ammoniak
Alle organischen Moleküle
```

## Kernfusion in Sternen

### Wie entstehen Sterne?

**1. Gravitationskollaps**

```
Molekülwolke (10^4 - 10^6 M_☉)
→ Fragmentierung
→ Kollaps einzelner Kerne
→ Protostern
```

**2. Virialisierung**

```
Gravitationsenergie → Kinetische Energie
E_pot = -2 · E_kin (Virialsatz)

Temperatur steigt:
T_center ~ M^2/R
```

**3. Fusion zündet**

```
Für M > 0.08 M_☉:
T_center > 10^7 K
→ p + p → D + e⁺ + νₑ
→ Sterngeburt!
```

### Proton-Proton-Kette

**Hauptsequenz-Sterne (M < 1.5 M_☉):**

```
Schritt 1: p + p → D + e⁺ + νₑ
Schritt 2: D + p → ³He + γ
Schritt 3a: ³He + ³He → ⁴He + 2p

Netto: 4p → ⁴He + 2e⁺ + 2νₑ + Energie
```

**Energieausbeute:**

```
Δm = 4m_p - m_He = 0.7% der Masse
E = Δm · c² = 26.7 MeV

Pro kg Wasserstoff:
E = 6.3 × 10^14 Joule

Sonne verbraucht:
~600 Mio Tonnen H/Sekunde
```

### CNO-Zyklus

**Massereiche Sterne (M > 1.5 M_☉):**

```
¹²C + p → ¹³N + γ
¹³N → ¹³C + e⁺ + νₑ
¹³C + p → ¹⁴N + γ
¹⁴N + p → ¹⁵O + γ
¹⁵O → ¹⁵N + e⁺ + νₑ
¹⁵N + p → ¹²C + ⁴He

Netto: 4p → ⁴He + 2e⁺ + 2νₑ
```

**Katalysator:** C, N, O (aus vorheriger Generation!)

## Die Elemententstehung

### Helium-Brennen

**Nach H-Erschöpfung im Kern:**

```
Kern kontrahiert → T steigt
T_center > 10^8 K
→ He-Fusion zündet

³He + ⁴He → ⁷Be + γ
oder
⁴He + ⁴He → ⁸Be (instabil!)
⁸Be + ⁴He → ¹²C + γ (Triple-Alpha!)
```

**Kohlenstoff entsteht!**

```
¹²C + ⁴He → ¹⁶O + γ

→ C und O sind Grundbausteine des Lebens
```

### Schwerere Elemente

**In massereichen Sternen (M > 8 M_☉):**

```
C-Brennen (T ~ 6×10^8 K):
¹²C + ¹²C → ²⁴Mg + γ
           → ²³Na + p
           → ²⁰Ne + α

Ne-Brennen (T ~ 1.2×10^9 K):
²⁰Ne + γ → ¹⁶O + α

O-Brennen (T ~ 1.5×10^9 K):
¹⁶O + ¹⁶O → ³²S + γ
            → ²⁸Si + α

Si-Brennen (T ~ 2.7×10^9 K):
²⁸Si + α → ³²S
³²S + α → ³⁶Ar
... → ⁵⁶Fe
```

### Eisengrenze

**Warum endet es bei Eisen?**

```
Bindungsenergie pro Nukleon:
E_B/A maximal bei ⁵⁶Fe (8.8 MeV)

Leichter als Fe: Fusion gibt Energie
Schwerer als Fe: Fusion braucht Energie

→ ⁵⁶Fe ist das stabilste Element!
```

**Sternstruktur vor Supernova:**

```
     ┌─────┐
     │  H  │  ← Hülle
     ├─────┤
     │ He  │
     ├─────┤
     │  C  │
     ├─────┤
     │  O  │
     ├─────┤
     │ Si  │
     ├─────┤
     │ Fe  │  ← Kern (Endstation)
     └─────┘
```

## Supernovae

### Kernkollaps

**Was passiert?**

```
Fe-Kern wächst → M_core > 1.4 M_☉
→ Elektronen-Entartungsdruck reicht nicht
→ Kernkollaps in ~1 Sekunde!
```

**Ablauf:**

```
1. Photodissoziation:
   ⁵⁶Fe + γ → 13 ⁴He + 4n
   (braucht Energie → Kern kühlt)

2. Neutronisierung:
   p + e⁻ → n + νₑ
   (Neutrinos entweichen → Energie weg)

3. Kollaps:
   R: 5000 km → 20 km in 0.1s!
   ρ: 10^9 → 10^15 g/cm³

4. Rebound:
   Neutrondruck stoppt Kollaps
   → Schockwelle nach außen
```

### Elementsynthese in Supernovae

**R-Prozess (rapid neutron capture):**

```
Neutronenfluss: ~10^24 n/cm²/s
Zeitskala: Millisekunden

Schwere Kerne fangen viele n ein:
⁵⁶Fe + n → ⁵⁷Fe + γ
⁵⁷Fe + n → ⁵⁸Fe + γ
...
Bis instabil → β⁻-Zerfall
```

**Ergebnis:** Alle Elemente schwerer als Fe!

```
Gold (Au):  R-Prozess
Platin (Pt): R-Prozess
Uran (U):   R-Prozess
Thorium (Th): R-Prozess
```

**S-Prozess (slow neutron capture):**

```
In AGB-Sternen (asymptotic giant branch):
Neutronenfluss: ~10^8 n/cm²/s
Zeitskala: Jahre

Zwischenschwere Elemente:
Sr, Y, Zr, Ba, La, Ce, Pb
```

### Supernova-Überrest

**Was bleibt?**

```
M_core < 3 M_☉: Neutronenstern
M_core > 3 M_☉: Schwarzes Loch
```

**Was wird verteilt?**

```
Masse ausgeworfen: ~10 M_☉
Energie: ~10^51 erg (Foe)
Elemente: ALLES außer H, He

→ Anreicherung des interstellaren Mediums
→ Nächste Sterngeneration ist reicher an "Metallen"
```

## Triple-Alpha-Prozess

### Das Kohlenstoff-Problem

**Naives Modell scheitert:**

```
⁴He + ⁴He → ⁸Be
Aber: ⁸Be ist instabil!
τ_½ = 10^-16 s

→ ⁸Be zerfällt sofort
→ Kein ¹²C?
→ Kein Leben?
```

### Hoyle-Resonanz

**Fred Hoyle (1954) postulierte:**

> "Weil wir existieren, MUSS es eine Resonanz geben!"

**Die Lösung:**

```
⁸Be + ⁴He → ¹²C*

¹²C* muss Resonanzzustand bei ~7.65 MeV haben
Experimentell gefunden: 7.654 MeV ✓

→ Resonanzverstärkung: Faktor 10^8
→ C-Produktion möglich
→ Leben möglich
```

**Mathematisch:**

```
σ(E) = σ₀ · (Γ/2)² / [(E-E_R)² + (Γ/2)²]

Bei E ≈ E_R: σ riesig!
```

### Fine-Tuning

**Wie fein abgestimmt?**

```
Wenn E_R um 0.1 MeV anders:
→ Keine C-Produktion
→ Kein Leben

Wenn starke Kraft 0.5% anders:
→ Entweder kein C oder kein O
→ Kein Leben
```

**Anthropisches Argument:**

```
Wir beobachten ein Universum mit:
- ¹²C-Resonanz
- Stabilen Sternen
- Leben

Warum? Weil wir sonst nicht da wären!
```

## Stellare Evolution

### Hauptreihe

**Dauer abhängig von Masse:**

```
M (M_☉) | T_core (K) | L (L_☉) | τ_MS (Jahre)
--------|------------|---------|-------------
0.1     | 3×10^6     | 0.001   | 10^13
0.5     | 1.5×10^7   | 0.03    | 10^11
1.0     | 1.5×10^7   | 1.0     | 10^10
5.0     | 3×10^7     | 1000    | 10^8
20.0    | 4×10^7     | 10^5    | 10^7

Faustregel: τ_MS ∝ M^(-2.5)
```

**Massiv = kurzlebig:**

```
Je mehr Masse → höhere Temperatur
→ schnellere Fusion → höhere Leuchtkraft
→ früher Brennstoff aus → kürzer leben
```

### Nach der Hauptreihe

**Sonnenähnliche Sterne (M < 8 M_☉):**

```
1. Roter Riese
   - H-Schale brennt
   - Hülle expandiert
   - L × 1000

2. Helium-Flash
   - He-Kern zündet schlagartig
   - Core-Helium-Brennen

3. AGB (Asymptotic Giant Branch)
   - He-Schale + H-Schale
   - Thermische Pulse
   - Planetarischer Nebel

4. Weißer Zwerg
   - C/O-Kern
   - Elektronen-Entartung
   - Abkühlen über Billiarden Jahre
```

**Massereiche Sterne (M > 8 M_☉):**

```
1. Roter Überriese
   - Betelgeuse, Antares
   - R ~ 1000 R_☉

2. Schalenstruktur
   - Zwiebelschalen-Modell
   - Alle Brennphasen

3. Supernova Typ II
   - Kernkollaps
   - Neutronenstern/BH

4. Anreicherung ISM
   - Schwere Elemente
   - Nächste Generation
```

### Warum Sterne essentiell sind

**Ohne Sterne:**

```
Kein Kohlenstoff → Keine org. Chemie
Kein Sauerstoff → Kein Wasser, keine Atmung
Kein Stickstoff → Keine Aminosäuren
Kein Eisen → Kein Blut
Kein Phosphor → Keine DNA
Kein Kalzium → Keine Knochen

→ KEIN LEBEN
```

**Mit Sternen:**

```
Fusion → Leichte Elemente
Supernova → Schwere Elemente
Verteilung → ISM angereichert
Neue Sterne + Planeten → Habitable Welten
Zeit + Chemie → Leben

→ WIR
```

### Das große Bild

**Sterne sind:**

1. **Energiequellen**
   - Licht, Wärme
   - Photosynthese
   - Klimastabilität

2. **Element-Fabriken**
   - C, N, O, Fe, ...
   - Alle schweren Elemente
   - Bausteine des Lebens

3. **Zeitgeber**
   - Langlebigkeit erlaubt Evolution
   - Stabilität über Milliarden Jahre
   - "Goldilocks"-Bedingungen

4. **Kosmische Recycler**
   - Tod → Geburt
   - Anreicherung über Generationen
   - Fortschritt zur Komplexität
