# SSZ Research Companion

A curated companion corpus for Segmented Spacetime (SSZ) and JIF research.

**Authors:** Carmen N. Wrede and Lino P. Casu  
**Status:** archived reference collection

## Scope

This repository brings together explanatory notes, formula maps, validation
guides, cross-repository indexes, and reproducibility material used alongside
the SSZ/JIF software repositories.

The collection helps readers locate canonical definitions, trace equations to
implementations and tests, distinguish types of evidence, navigate the wider
repository family, reproduce documented workflows, and identify unresolved
questions.

The files are research documentation, not a substitute for independent review.
The presence of an item in this collection does not by itself establish an
empirical claim.

## Repository structure

```text
DEEP_KNOWLEDGE_WIKI/   structured theory and validation guides
markdowns/             source-repository documentation snapshots
SSZ_PROJECT_PART_*     thematic reference chapters
SSZ_*                  canonical maps, audits, and syntheses
index_*                navigation and cross-repository indexes
```

Manuscripts, publication PDFs, credentials, private keys, local environments,
caches, and build artifacts are intentionally excluded from the public
release.

## Reproducibility and interpretation

Follow the source and provenance notes inside each document. Treat numerical
agreement according to its declared category: identity check, model
regression, engineering reference, or empirical comparison. Do not infer
strong-field confirmation from weak-field compatibility.

When citing this collection, use:

> Carmen N. Wrede and Lino P. Casu, *SSZ Research Companion*.

For specific scientific claims, cite the primary source identified in the
relevant document.
